# ADR-021: Frontend stack for the Telegram Mini App

- **Status:** Accepted
- **Date:** 2026-10-19
- **Related:** REQ-012, REQ-013 · T34–T39

## Context

The spec stack is React, TypeScript and Vite, served as static files by the existing Nginx inside a Telegram webview.

## Decision

- Vite + React + TypeScript (strict).
- Telegram WebApp JS (`telegram-web-app.js`) for `initData` and theme.
- TanStack Query for server state, React Router, no UI kit beyond Telegram theme CSS variables.
- Built files deploy to `/var/www/clipforge-bot`.

## Consequences

- Small bundle, native Telegram look.
- Custom components for anything beyond basic controls.
