# ADR-011: Windowed analysis of long transcripts

- **Status:** Accepted
- **Date:** 2026-10-19
- **Related:** REQ-008 · T21

## Context

Transcripts of 120-minute videos are long; sending everything (plus frames) in one call is costly, slow and hits free-tier limits.

## Decision

- Split the transcript into overlapping ~8–10 minute windows; request candidates per window as structured JSON validated by Pydantic (one repair retry).
- Run a re-rank pass over the shortlist; sampled low-resolution frames are sent only for shortlisted windows.

## Consequences

- Bounded cost and latency; vision is used only where it matters.
- Candidates spanning window edges rely on window overlap.
