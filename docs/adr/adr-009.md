# ADR-009: Provider-independent AI adapters with registry and job snapshot

- **Status:** Accepted
- **Date:** 2026-10-19
- **Related:** REQ-007, REQ-008 · T17

## Context

The spec defines `TranscriptionProvider` and `ViralAnalysisProvider` protocols, separate configuration per capability, server-side credentials, and a snapshot of selected models per job.

## Decision

- Protocols `TranscriptionProvider`, `ViralAnalysisProvider` and `EmbeddingProvider` (affiliate).
- A registry builds adapters from `ai_provider_configs`; secrets are referenced by env-var name (`secret_ref`) and never stored in the database.
- The resolved configuration is snapshotted into the job when it is claimed.
- Deterministic fake providers exist for tests.

## Consequences

- Swapping models or providers is configuration, not code.
- Running jobs are unaffected by configuration edits.
