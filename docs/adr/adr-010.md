# ADR-010: Server-side scoring and pure candidate selection

- **Status:** Accepted
- **Date:** 2026-10-19
- **Related:** REQ-008, REQ-009 · T19

## Context

The spec defines the weighted score `0.25H + 0.20E + 0.20C + 0.15R + 0.10V + 0.10F`, a default threshold of 75, 20–60 s clips, at most 20 % overlap and up to three clips. LLM arithmetic is unreliable.

## Decision

- The AI returns only the six dimension scores; the server computes the total with the spec formula and ignores any model-provided total.
- Selection is a pure function: threshold, snap to transcript segment boundaries, clamp to the configured duration range, ≤ configured pairwise overlap, top N (≤ 3).

## Consequences

- Deterministic and unit-testable.
- The score is a ranking heuristic, not a probability of going viral.
