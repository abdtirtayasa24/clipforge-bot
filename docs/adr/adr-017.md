# ADR-017: Chunked resumable uploads

- **Status:** Accepted; the permission evidence part is superseded by ADR-031; amended by ADR-032 (one upload at a time)
- **Date:** 2026-10-19
- **Related:** REQ-005, REQ-006 · T13, T36

## Context

Nginx keeps `client_max_body_size 10m`; the spec requires large uploads in bounded chunks.

## Decision

- `POST /uploads` declares size, sha256 and permission evidence.
- `PATCH /uploads/{id}` with `Content-Range`, chunks ≤ 8 MiB, appended at the exact offset.
- `POST /uploads/{id}/complete` verifies size and sha256, runs ffprobe validation and rights checks.
- Clients resume by querying the current offset.

## Consequences

- Large files upload over flaky mobile connections.
- The Mini App must hash the file client-side (Web Worker).
