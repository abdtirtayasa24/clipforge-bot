# ADR-022: Observability: structured logs and redaction

- **Status:** Accepted
- **Date:** 2026-10-19
- **Related:** Should-Have (logs) · T01, T06

## Context

The spec asks for logs and forbids exposing secrets. Services run under systemd, which collects stdout into journald.

## Decision

- stdlib `logging` with a JSON formatter writing to journald.
- `contextvars` inject `request_id`, `job_id`, `stage` and `attempt` into every record.
- A redaction filter masks tokens, `initData`, `Authorization` headers and URL query strings.
- `job_events` holds business history; `provider_usage` holds AI usage and cost.

## Consequences

- Logs are searchable per job with `journalctl`.
- No external log shipping in the MVP.
