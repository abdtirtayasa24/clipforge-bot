# ADR-018: Permitted URL downloads via domain allowlist and SSRF guard

- **Status:** Accepted
- **Date:** 2026-10-19
- **Related:** REQ-005, REQ-006 · T14, T30, T39

## Context

Only creator-authorized media may be ingested, and the worker must not be usable for SSRF. Product owner decision (2026-10-19): restrict permitted URLs to an admin-maintained domain allowlist.

## Decision

- `app_settings.permitted_download_domains` holds exact hosts or `*.suffix` entries; empty by default, which disables URL ingestion until configured. Managed through `PATCH /settings` and the Settings screen.
- The worker downloads with an SSRF guard: https only; every redirect hop must be allowlisted and resolve to a public IP; max redirects; max size; streamed to disk with sha256.
- YouTube hosts can never be allowlisted.

## Consequences

- Strong protection against unauthorized sources and SSRF.
- The admin must add each media host before using it.
