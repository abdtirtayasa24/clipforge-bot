# ADR-014: Idempotent Google Drive uploads

- **Status:** Accepted
- **Date:** 2026-10-19
- **Related:** REQ-011 · T26

## Context

The spec requires resumable uploads, verification of file metadata and size, never deleting the only local copy before remote verification, and reconciliation of ambiguous upload completion. The pilot target is 0 duplicate uploads.

## Decision

- Each clip has a deterministic identity (`clip_id`) stored in Drive `appProperties.clipforge_clip_id`.
- Before creating a file, query Drive by that property and adopt a complete match.
- Persist the resumable session URI in `clip_artifacts` to resume interrupted uploads.
- Verify `size` and `md5Checksum` against the local file before persisting `drive_file_id`; delete the local file only after verification. Files stay private.

## Consequences

- Crashes at any point cannot create duplicates.
- One extra Drive query per clip.
