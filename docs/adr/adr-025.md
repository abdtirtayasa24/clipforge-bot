# ADR-025: Generated clip titles from the analysis pass

- **Status:** Accepted
- **Date:** 2026-10-19
- **Related:** Should-Have (generated titles) · T21, T22, T24, T29, T33, T37

## Context

The spec lists generated titles as a Should-have. A separate title call would add cost and quota use.

## Decision

- Each `ClipCandidate` carries `title` (≤ 70 chars, transcript language, no claims absent from the transcript) and `hook_line`, produced by the analysis pass.
- The title is stored on `clip_candidates` and copied to `clips.title`; the admin may override it at review (`clips.title_override`, original kept).
- Captions, Drive file names and notifications use the effective title (override, else generated).

## Consequences

- No extra AI cost; titles stay grounded in the segment.
- No alternative title variants in the MVP.
