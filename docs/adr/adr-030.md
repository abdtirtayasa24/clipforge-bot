# ADR-030: Continuous integration on GitHub Actions

- **Status:** Accepted
- **Date:** 2026-10-19
- **Related:** All tasks · T45

## Context

Product owner decision (2026-10-19): add CI, which the spec does not mention.

## Decision

- Backend job: `astral-sh/setup-uv` → `uv venv` → `uv pip install -e "./backend[dev]"` → ffmpeg from apt → ruff check, ruff format check, mypy, pytest with a `postgres:17` service; fails if any direct dependency lacks an exact pin.
- Frontend job: `npm ci`, lint, typecheck, vitest, build.
- Live-provider tests (`-m live`) never run in CI; no secrets required. Third-party actions are pinned to commit SHAs.

## Consequences

- Regressions and transitive-dependency breakage are caught before deployment.
- CI time grows with the test suite.
