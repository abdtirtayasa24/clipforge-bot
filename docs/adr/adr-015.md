# ADR-015: Google Drive OAuth and token encryption

- **Status:** Accepted
- **Date:** 2026-10-19
- **Related:** REQ-011 · T25

## Context

The spec stores an encrypted Google Drive refresh token in `oauth_credentials`.

## Decision

- OAuth with the admin's Google account, `drive.file` scope.
- `state` is bound to the admin session and single-use.
- The refresh token is encrypted at rest with a Fernet key from the environment.

## Consequences

- Least-privilege access to Drive.
- The Fernet key must be backed up and rotated per the runbook; losing it requires reconnecting Drive.
