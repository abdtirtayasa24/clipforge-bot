# ADR-020: Affiliate product matching

- **Status:** Accepted
- **Date:** 2026-10-19
- **Related:** REQ-017–REQ-019 · T32

## Context

The spec requires admin-curated products only, a default-off toggle, a 0.70 minimum relevance, up to three suggestions per clip with one primary, and never inventing links.

## Decision

- Filter active catalog products by language/region and tag/category overlap.
- Rank by embedding similarity (`gemini-embedding-2`; product embeddings cached and recomputed only when a product changes), otherwise a keyword/BM25-style fallback.
- Threshold 0.70; at most 3 suggestions; the top one is flagged primary.
- The toggle is checked both when matching and when exporting. Disclosure text is a setting with the spec default.

## Consequences

- No match produces no link.
- Embedding calls count against the free-tier quota (see ADR-028).
