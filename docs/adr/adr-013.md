# ADR-013: Clip rendering profile

- **Status:** Accepted
- **Date:** 2026-10-19
- **Related:** REQ-010 · T23, T24

## Context

The spec requires 720×1280 MP4, H.264/AAC with burned subtitles, on a 2 vCPU VPS. Subject-aware reframing is a Could-have.

## Decision

- Center crop/scale to 720×1280.
- `libx264 -preset veryfast -crf ~23`, AAC 128k, `+faststart`; subtitles burned from a generated ASS file.
- Output verified with ffprobe: dimensions, codecs, duration within ±0.5 s.

## Consequences

- Predictable CPU cost and output quality.
- Speakers off-center may be cropped until subject-aware reframing is added.
