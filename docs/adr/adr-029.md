# ADR-029: Clip preview via external Google Drive link

- **Status:** Accepted
- **Date:** 2026-10-19
- **Related:** REQ-013 · T37

## Context

Product owner decision (2026-10-19): open the Drive file externally rather than streaming clips through the backend. Clips are private files in the admin's Drive.

## Decision

- The Mini App calls `Telegram.WebApp.openLink(webViewLink)`.
- No streaming proxy endpoint is added to the API contract.

## Consequences

- No media bandwidth through the VPS and no API additions.
- The admin must be signed in to the uploading Google account on the phone.
