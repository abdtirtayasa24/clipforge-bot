# ADR-016: Telegram initData authentication and session tokens

- **Status:** Accepted
- **Date:** 2026-10-19
- **Related:** REQ-012 · T05

## Context

The spec requires server-verified Telegram Mini App `initData`, freshness checks and a single administrator.

## Decision

- Verify `initData` with HMAC-SHA256 (`secret = HMAC("WebAppData", bot_token)`), constant-time compare, reject `auth_date` older than a configurable window (default 1 h), require `user.id` in `admin_users`.
- Issue a 12 h HMAC-signed session token sent as `Authorization: Bearer`.
- All `/api/v1/*` routes require it except `/auth/telegram`, `/health/*` and the Drive OAuth callback.

## Consequences

- Bearer tokens work reliably inside Telegram webviews.
- Tokens live in memory in the Mini App; reopening the app re-authenticates.
