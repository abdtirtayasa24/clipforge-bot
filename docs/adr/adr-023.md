# ADR-023: Testing strategy

- **Status:** Accepted
- **Date:** 2026-10-19
- **Related:** All tasks · T02, T45

## Context

Tests must be fast and deterministic, must not hit paid or rate-limited services by default, and must never touch Supabase.

## Decision

- pytest + pytest-asyncio.
- Integration tests use a disposable PostgreSQL via `CLIPFORGE_TEST_DATABASE_URL` (`clipforge_test` on local PostgreSQL 17 in development, a `postgres:17` service container in CI).
- HTTP mocked with `respx`; media tests use tiny ffmpeg-generated fixtures (`testsrc` + `sine`).
- Real-provider and real-Drive tests are opt-in (`-m live`) and never run in CI.

## Consequences

- CI needs no secrets.
- Live behavior of providers is only verified manually or with `-m live`.
