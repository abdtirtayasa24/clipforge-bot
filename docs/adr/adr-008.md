# ADR-008: Async subprocesses for media work

- **Status:** Accepted
- **Date:** 2026-10-19
- **Related:** REQ-015 · T09, T16, T24

## Context

FFmpeg work can take minutes on a 2 vCPU VPS with `CPUQuota=170%`. If it blocks the event loop, lease heartbeats stop and the job looks abandoned.

## Decision

- ffmpeg/ffprobe run via `asyncio.create_subprocess_exec`, never blocking calls.
- ffmpeg uses `-threads 2`; one render at a time.

## Consequences

- Heartbeats keep running during long encodes.
- Subprocess output must be captured and size-limited to avoid memory growth.
