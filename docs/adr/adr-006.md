# ADR-006: Job stage state machine with durable stage artifacts

- **Status:** Accepted; stage list superseded by ADR-034
- **Date:** 2026-10-19
- **Related:** REQ-014 · T09, T22

## Context

Processing a 60–120 minute video is long and pays for AI calls. A restart must resume from the last completed stage instead of repeating paid or slow work.

## Decision

- Explicit stages: `awaiting_source → queued → ingesting → validated → audio_extracted → transcribed → analyzed → candidates_selected → rendering → uploading → affiliate_matching → completed`, plus terminal `completed_no_clips`, `failed`, `cancelled`.
- Each stage is idempotent and first checks for its durable, checksum-verified artifact before redoing work.

## Consequences

- Restarts are cheap and safe.
- Every stage must define its artifact and verification; stage outputs consume workspace disk until cleanup.
