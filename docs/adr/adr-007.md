# ADR-007: Error taxonomy and retry policy

- **Status:** Accepted
- **Date:** 2026-10-19
- **Related:** REQ-014 · T08

## Context

The spec asks for bounded exponential retries (about 1, 5, 15 minutes plus jitter) and forbids retrying permanent rights/validation errors.

## Decision

- `PermanentError`: rights, validation, unsupported media — job fails, never retried.
- `TransientError`: network, 5xx, timeouts, rate limits — retried at ~1 / 5 / 15 min + jitter, max 3 attempts.
- `LeaseLost`: abort the stage silently; another worker owns the job.
- `Cancelled`: admin requested cancellation; job ends `cancelled`.

## Consequences

- Failure handling is uniform across stages and visible in `job_events`.
- Adapters must map provider errors into this taxonomy.
