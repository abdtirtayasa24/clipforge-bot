# ADR-019: YouTube discovery for Indonesia with dynamic trending categories

- **Status:** Accepted
- **Date:** 2026-10-19
- **Related:** REQ-001–REQ-004 · T10, T11

## Context

Product owner decision (2026-10-19): use the Indonesian region and the categories trending in the current period. The YouTube Data API quota is 10,000 units/day; `search.list` costs 100 units, `videos.list` 1 unit.

## Decision

- Each run fetches `videos.list(chart=mostPopular, regionCode=ID, maxResults=50)` × 4 pages (the full 200-video chart).
- Count `snippet.categoryId` in that chart and pick the **top 5 categories** (ignoring `discovery.excluded_category_ids`).
- Fetch each top category's chart (`videoCategoryId`, 50 results); a category without a chart returns 404 and is skipped.
- Channels use `channels.list → uploads playlist → playlistItems.list` plus batched `videos.list`.
- Filter by ISO-8601 duration 30–120 min; dedupe on unique `videos.youtube_video_id`; `video_sources` records every source (including category) that surfaced a video.
- Keep up to **20 newly eligible videos per run**, ranked by views per hour since publish.

## Consequences

- About 9–10 quota units per trending run.
- The Indonesian trending chart is mostly short videos, so few 30–120 min candidates are expected; monitored channels are the more reliable long-form source.
